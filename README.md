# Hair Day

![Status](https://img.shields.io/badge/status-em_desenvolvimento-yellow)

O **Hair Day** é uma aplicação web voltada para o agendamento e a gestão diária de cortes de cabelo. O sistema permitirá selecionar data, horário disponível e cadastrar o nome do cliente para criar novos agendamentos, além de consultar as reservas do dia.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** & **CSS3**
- **JavaScript (ES6+)**
- **Webpack** & **Babel**
- **Day.js** (manipulação de datas)
- **JSON Server** (simulação de API REST)

---

## 🚀 Funcionalidades

- **Agendamento de Horários:** Seleção de data, horário disponível e cadastro do nome do cliente.
- **Listagem Diária:** Visualização clara dos cortes de cabelo agendados para o dia selecionado.
- **Bloqueio de Horários:** Identificação e bloqueio de horários já ocupados.
- **Gestão de Agendamentos:** Remoção/cancelamento de agendamentos diretamente pela interface.
